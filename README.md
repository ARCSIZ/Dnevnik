# Исправление главной страницы и вкладок расписания

Архив содержит только изменённые файлы приложения:
- `server.js` — корректное сопоставление группы и студента со старыми записями базы; возврат группового/старого общего расписания, если у группы пока пустой шаблон; исправление сопоставления studentIndex для отображения оценок и посещаемости.
- `diary.html` — устойчивое переключение между вкладками «Расписание» и «Мероприятия», включая синхронизацию визуального состояния и повторный рендер.

## Установка на BotHost

1. Остановите приложение.
2. Скачайте резервную копию текущей базы (`/app/data/data.json`, а также `/app/data.json`, если он существует).
3. Распакуйте архив локально и замените в текущем проекте **только** `server.js` и `diary.html`.
4. Не загружайте поверх рабочей базы файл `data.json` из старых архивов и не удаляйте `/app/data`.
5. Выполните новый деплой.
6. После запуска проверьте главную страницу под студенческим аккаунтом и переключение «Расписание» → «Мероприятия» → «Расписание».

В архиве нет `data.json`, поэтому он не перезапишет базу пользователей.
