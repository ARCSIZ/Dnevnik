# Исправление восстановления оценок и расписания

Этот архив содержит только `server.js` и `README.md`. Файл `data.json` в него намеренно не включён.

## Что исправлено

- Если в старой базе заполнено общее расписание `sch`, а расписания групп пусты, сервер переносит прежнее расписание в расписания соответствующих групп.
- Старое время пар `times` переносится в группы, если у групп ещё нет своих настроек времени.
- Если у старых аккаунтов студентов/старост отсутствовал `studentIndex`, сервер пытается найти студента в массиве `students` по ФИО или добавить имя в конец списка. Существующие корректные индексы не меняются.
- Оценки `grades`, посещаемость `att`, домашние задания и другие поля не очищаются.
- При запуске в логах выводятся только количества оценок/отметок/занятий и активный путь к базе. Сами персональные данные не выводятся.
- Сохраняются предыдущие исправления: учёт `DATA_DIR`/`DATA_FILE` и отказ перезаписывать повреждённый JSON пустой базой.

## Безопасный порядок

1. Остановить приложение.
2. Скачать текущий `data.json` в резервную копию.
3. В архиве заменить **только** `server.js`. Не загружать и не удалять `data.json`.
4. Запустить новый деплой.
5. Посмотреть строку `База данных:` в логах: сравнить число оценок, отметок посещаемости и занятий с ожидаемым.

Важно: этот патч способен восстановить отображение расписания из старого общего поля `sch` и сопоставить недостающие индексы студентам, но он не может воссоздать оценки, если их уже нет в активной базе или в резервной копии. Для оценки такого случая нужны старый и текущий `data.json` (их можно загрузить сюда; секреты/токены перед отправкой удалите).
